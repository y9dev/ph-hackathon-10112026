# MVP — Modus Voice
Полный состав и приёмка: `docs/PRD.md` §5, §10. Здесь только критический путь для питча.

## Критический путь (один сценарий)
Сотрудник подаёт обращение (можно анонимно) → система находит владельца и срок → владелец ведёт его по стадиям «Разработка → Принятие решения → Реализация» → фиксирует результат → автор видит итог → руководство видит метрики и повторяющиеся проблемы.

## Четыре опоры
1. **Подача за минуту:** тип, категория, текст, вложения, полная анонимность по токену.
2. **Маршрут и срок:** правила категория → подразделение → владелец → срок, очередь «не распределено», просрочка.
3. **Решение с результатом:** статусы, уточнения, отчёты о ходе, закрытие только с результатом.
4. **Видимость:** четыре метрики из ТЗ, повторяющиеся проблемы, уведомления в системе и в Telegram.

## Won't (осознанно не делаем)
Реальные интеграции с Битрикс24 и 1С (только проработка), ML-классификация, мобильное приложение, мультиарендность, клиентские опросы.

# Вероятные вопросы жюри и ответы

**Как гарантируете, что обращение не потеряется?** Каждое получает владельца по правилу или попадает в очередь «не распределено» у админа; у него срок первого ответа, просрочка подсвечена и уведомляет; закрыть без результата нельзя (тесты маршрутизации и SLA).

**Насколько анонимность настоящая?** У анонимного обращения нет автора в БД; доступ по токену из 28 символов, хранится только SHA-256, показывается один раз. Минус: потерянный токен не восстановить, текст и вложения могут выдать автора (указано в интерфейсе и README).

**Что реально работает, а что имитация?** Работает всё из таблицы README «Реализовано». Битрикс24, 1С, e-mail, SSO только проработаны. Telegram проверен на поддельном Bot API, с реальным токеном не проверялся.

**Как подключить к Битрикс24?** Адаптеры за портами `DirectoryProvider`, `IdentityProvider`, `TaskSink`, `Notifier` (`docs/INTEGRATIONS.md`). Нужны ответы компании: облако или on-prem, источник идентификации, поле руководителя отдела.

**Почему Go и SQLite?** Один бинарник, простое развёртывание в периметре компании (заказчик с критичными объектами). До ~1000 пользователей хватает SQLite, дальше PostgreSQL за теми же интерфейсами.

**Как находите повторяющиеся проблемы?** Эвристика по сходству текста внутри категории, предлагает группы руководителю, тот подтверждает. Это не ML; на датасете дублей нет, поэтому на демо группа появляется после ввода трёх похожих обращений.

**Как измерите успех?** Четыре метрики ТЗ в аналитике; на пилоте: ≥80% первых ответов в срок, ≥60% опрошенных готовы пользоваться дальше.

**Что дальше, если мы выберем вас?** Пилот на 4 недели в 1–2 подразделениях, затем интеграция с Битрикс24 (`ROADMAP.md`).

**Слабые места, которые вы знаете?** Блокировка входа по почте администратора перебором; период аналитики по умолчанию и пустые «Повторяющиеся проблемы» на датасете; нет проверки с реальным Telegram-токеном; нет интервью с сотрудниками. Часть уже исправлена в последних коммитах, остальное в плане пилота.

**Почему не взять готовое?** Готовые платформы идей работают во внешнем облаке и не знают оргструктуру компании; задачи Битрикс24 не принимают анонимные идеи и не маршрутизируют по категории (`MARKET.md`, проверено по описаниям, не на живых продуктах).

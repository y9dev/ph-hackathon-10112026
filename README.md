# Modus Voice — система обратной связи и предложений сотрудников

Хакатон ГК «Модус Трейд». Сотрудник за минуту сообщает о проблеме или предлагает улучшение, система сама направляет обращение ответственному со сроком ответа, а автор видит решение. Все обращения и решения сохраняются, поэтому руководство видит повторяющиеся проблемы и реально внедрённые улучшения.

**Формат результата:** работающий MVP (ТЗ п. 4.3). Сверка с ТЗ: [docs/TZ_COMPLIANCE.md](docs/TZ_COMPLIANCE.md).

## Быстрый запуск

### Вариант 1. Docker (рекомендуется для жюри)
```bash
docker compose up --build
```
Откройте http://localhost:8080. Данные синтетические, загружаются автоматически при первом запуске.

### Вариант 2. Go + Node
Нужны Go 1.26+ и Node 22+.
```bash
make web-build       # собрать интерфейс в backend/internal/webui/dist
make backend-demo    # запустить сервер с демо-данными на :8080
```
Разработка: `make backend-demo` в одном терминале, `cd web && npm run dev` в другом (http://localhost:5173, прокси на :8080). Интерфейс без бэкенда: `cd web && npm run dev:mock`.

## Известные ограничения
- Данные синтетические; хранилище SQLite (один узел). Переход на PostgreSQL описан в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- Анонимность псевдо: автор хранится в БД, чтобы отслеживать обращение и отвечать на уточнения. Содержание, вложения и время могут подсказать личность автора.
- Оргструктура плоская (подразделение → руководитель), без иерархической эскалации.
- Обращение после закрытия не открывается повторно: автор создаёт новое со ссылкой на старое.
- Ограничитель попыток входа считает по адресу соединения; за обратным прокси его нужно настроить отдельно.
- Ручной проход с экранным диктором и измерение контраста всех тем не проводились (см. [docs/QUALITY_SCORECARD.md](docs/QUALITY_SCORECARD.md)).

## Структура проекта
```
backend/            Go: cmd/server, internal/{app,platform,modules,integrations,seed,webui}, migrations
  internal/modules/ identity · org · requests · insights · notifications (одинаковая структура модуля)
web/                React + TypeScript + Vite: src/{app,shared,features}, e2e
docs/               PRD, ARCHITECTURE, UX_SPECIFICATION, INTEGRATIONS, TZ_COMPLIANCE, api/openapi.yaml
```
Новый модуль = папка в `backend/internal/modules/` + строка в `backend/internal/app/modules.go`; новая фича интерфейса = папка в `web/src/features/` + запись в роутере. Подробности: [backend/README.md](backend/README.md), [web/README.md](web/README.md).

